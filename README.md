# E-Learning Android Application

## Project Overview
E-Learning is an Android application developed using Java and XML. The application provides a simple platform for users to explore courses, enroll in courses, access lessons, track learning progress, manage their profile, and use dashboard features.

## Technologies Used
- Java
- XML
- Android Studio
- Android SDK

## Features
- Welcome screen
- User Login
- User Registration
- Home screen
- Course browsing
- Course enrollment
- Python lessons
- Lesson completion tracking
- Learning progress tracking
- Dashboard
- Profile management
- Logout

## Course
The application includes a Python Programming course with:
- Python Basics
- Variables
- Functions

## Learning Progress
Users can mark lessons as completed and track their learning progress through the dashboard.

## Project Structure
- `app` - Android application source code
- `res/layout` - XML layout files
- `src/main/java` - Java source files
- `AndroidManifest.xml` - Application configuration

## How to Run
1. Open the project in Android Studio.
2. Wait for Gradle synchronization to complete.
3. Select an Android Emulator or connected device.
4. Click the Run button.
5. The E-Learning application will launch.
